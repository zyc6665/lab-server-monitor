# v1.4 桌面客户端化、PVS 风格 UI、主机连接向导与 SSH 终端实施计划

**Goal:** 将 v1.3.1 的 Electron 套网页工具升级为 Windows 桌面客户端：无边框窗口/自定义标题栏、纯本机回环、PVS 风格全站 UI、三步添加主机向导、多标签内置 SSH 终端（仅本机、仅元数据审计）。

**Architecture:** 保留 Electron 主进程 + Python PyInstaller sidecar；后端新增 `ssh_terminal.py`（Paramiko shell 会话管理）、`host_probe.py`（连接测试与自动识别）、`ssh_audit.py`（会话元数据）；前端继续原生 Jinja2/CSS/JS，xterm.js 以静态 vendor 方式离线内置；终端采用 SSE 输出 + POST 输入的 HTTP 协议，Waitress 线程池扩容到 32；桌面模式强制回环，移除局域网访问。

**Tech Stack:** Python 3.12、Flask、waitress、paramiko、SQLite、Jinja2、原生 JS、xterm.js（vendored）、Electron 45.2.3 / electron-builder 26.18.0、PyInstaller 6.x。

**Spec:** `docs/plans/2026-11-07-v1.4-desktop-client-design.md`

## Global Constraints

- 不引入前端框架、构建链或外部 CDN；xterm.js/字体/图标全部离线资源。
- 不保留局域网浏览器访问：桌面模式只监听 `127.0.0.1`；Docker/headless 模式不受影响。
- 终端只接受本机回环 + `SERVERMONITOR_DESKTOP=1`；不得记录终端输入输出，只记录元数据审计。
- 所有设置/终端写接口必须登录 + CSRF；秘密不入日志、不回显。
- 版本 1.4.0；绿色包由 `desktop/scripts/build-portable.ps1` 产出，文件名 `服务器轮询监测工具-Windows-x64-v1.4.zip`。
- 修改 PowerShell 脚本必须保留 UTF-8 BOM（PS5.1 中文路径要求）。
- 每个任务先写失败测试（pytest 或 node:test），实现后跑 focused/full；不得把 `dist/`、`release/`、`node_modules/` 提交。

## Review Focus

- 终端 SSE 长连接不会耗尽 Waitress 线程；断开/退出会释放会话。
- 纯本机绑定和终端权限确实阻断局域网。
- 主机向导秘密只内存使用，不落库/日志；错误不泄密。
- UI 在 Electron 无边框窗口中可拖动、可最小化/最大化/关闭，浏览器布局不崩。
- 文件路径/打包：xterm 静态资源、新模块 hiddenimports 都进入 PyInstaller 包。
