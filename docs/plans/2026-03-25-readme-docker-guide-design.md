# README Docker 傻瓜部署指南设计

## 目标

把当前 README 改写成面向新手的 Docker 部署手把手指南，让第一次接触这个项目的人可以按顺序完成：

- 准备目录
- 修改 `config.yaml`
- 修改 `.env`
- 启动容器
- 查看日志
- 调整定时
- 排查常见错误

## 已确认范围

- 只面向 Docker 部署
- 以 `docker compose` 为主线
- 使用当前已有的 `Dockerfile`、`docker-compose.yml`、`docker/entrypoint.sh`
- 不把本地 Python 运行作为主线

## 推荐结构

1. 这是什么
2. 你要提前准备什么
3. 第 1 步：准备目录和文件
4. 第 2 步：修改 `config.yaml`
5. 第 3 步：修改 `.env`
6. 第 4 步：启动容器
7. 第 5 步：检查是否成功
8. 第 6 步：修改定时发送时间
9. 常见报错怎么处理
10. 常用命令

## 写作原则

- 每一步只做一件事
- 每一步都给命令
- 每一步都写清“你要改什么”
- 默认读者不会 Docker、不会 SSH、不会 SMTP
- 只保留对部署有帮助的信息，避免原理性铺陈
