服务器轮询监测工具（ServerMonitor）v0.2.0（Windows 安装版）使用说明
====================================================

一、安装与首次启动
1. 运行 ServerMonitor-0.2.0-Setup.exe，按向导选择安装目录与数据目录
   （默认安装到 D:\Tools\ServerMonitor，无 D 盘时为 %LOCALAPPDATA%\Programs\ServerMonitor）。
   数据目录存放数据库、日志与运行时文件，升级与卸载默认保留。
   静默安装：ServerMonitor-0.2.0-Setup.exe /S /D=<安装目录>
2. 从开始菜单或桌面快捷方式启动。首次启动自动进入“初始化管理员”页面（/setup），
   设置管理员用户名和密码（至少 8 位），以后用该账号登录。
3. 关闭主窗口（点右上角 X）不会退出程序，而是最小化到系统托盘继续监测。
   右键托盘图标可：显示主窗口 / 打开日志目录 / 复制看板地址 / 退出。
   要彻底退出，请使用托盘菜单的“退出”（会先优雅停止后台服务）。

二、开机自启（可选）
在设置页或托盘菜单打开“开机自启”。登录 Windows 后程序只在托盘运行、不弹窗口；
关闭开关即取消自启。

三、网页在线设置
所有配置都在“设置”页完成：主机与 SSH、监控与存储、通知、报告、磁盘健康、看板与安全等，
无需手工编辑配置文件。敏感值（SSH 密码/私钥、邮箱密码、Webhook、sudo 密码）使用当前
Windows 账户 DPAPI 加密保存，界面永不回显原文。
- 看板只监听本机 127.0.0.1，不提供局域网访问。
- 主机密钥校验默认“首次信任并记录”；主机密钥变化会拒绝连接并提示两个指纹。
  主机重装系统后，在“已信任的主机密钥”里点“忘记”即可重新信任。

四、使用模式（管理员 / 用户）
设置页“监控与存储”卡片最下方的“使用模式”可二选一，切换后立即生效。
1. 管理员模式（默认）：可见全部功能（概览、主机、磁盘健康、告警、服务器用户、终端、设置）。
2. 用户模式（实验室成员）：填写“我的服务器账号名”（例如 zhouyc）。导航只剩“我的服务器”
   和“设置”；按主机显示账号是否存在、docker/sudo 组、家目录与 /data 所有者、权限和占用；
   账号不存在的主机标为“缺失”。管理员页面会被带回“我的服务器”，管理员接口返回 403。
3. 使用模式只是界面约束，不改变服务器上的实际权限；用户模式不提供任何写操作。

五、从 SSH 配置批量导入主机
1. “设置 → 主机与 SSH”，点“从 SSH 配置读取”，程序读取当前用户 .ssh\config 列出候选主机。
2. 勾选需要的主机（可勾选“覆盖同名”）导入；缺少私钥的主机标记为待补凭据。
3. 导入或新增主机后自动在后台采集一次状态和磁盘健康，完成后自动刷新。

六、自动更新
1. “设置 → 看板与安全 → 软件更新”点“检查更新”。
2. 有新版本时从 GitHub Release（zyc6665/lab-server-monitor）下载新安装包，
   按 latest.yml 校验 sha512，通过后安装并重启；数据目录保留。

七、从旧绿色包（v0.1.x zip 解压版）迁移
1. 旧绿色包内置的更新器无法升级到安装版，请到 GitHub Release 手动下载一次
   ServerMonitor-0.2.0-Setup.exe 并安装。
2. 安装版首次启动会自动导入旧目录中的 data\servermonitor.db（主机、历史、凭据）；
   凭据为 DPAPI 加密，须在同一台电脑、同一 Windows 账户下才能解密。
3. 确认数据无误后退出旧程序，备份旧目录的 config\、data\、logs\，再删除旧文件夹；
   旧的启动/停止/开机自启脚本不再使用，原计划任务可在任务计划程序中删除。

八、卸载
通过“设置 → 应用”或控制面板卸载。卸载时询问是否删除数据目录，默认“否”（保留）；
静默卸载（/S）一律保留数据。卸载前请先从托盘退出程序。

九、安全说明（重要）
- 敏感信息使用本机 Windows 账户加密（DPAPI），拷到另一台电脑会失效，需要重新 /setup 并填写凭据。
- 同一时间只运行一个实例；再次启动只会唤出已有窗口。
- sudo 密码只写不回显，不会写入命令、日志或导出报告。

十、日志与排错
- 日志位于数据目录下 logs\（desktop.log、servermonitor.log）；托盘“打开日志目录”可直达。
- 看板地址：托盘“复制看板地址”或设置页查看。
- 窗口打不开或提示“后台服务已停止”：查看日志确认端口未被占用，托盘“退出”后重新启动。
- 忘记管理员密码：退出程序后删除数据目录中的 servermonitor.db 重新初始化
  （会丢失历史与主机配置，请先记录主机信息）。

十一、账号管理（默认关闭）
1. 设置 → 服务器用户监控 → 勾选“允许账号写操作”（总开关）。
2. 设置 → 主机 → 编辑目标主机 → 勾选“允许账号写操作”，并填写该主机的 sudo 密码。
3. “服务器用户”页 → 选择主机 → “新建账号”，或账号卡片上的
   “重置密码 / 加入 docker 组 / 建 data 目录”。
4. 点“预览执行计划”核对命令，再分别输入主机名与账号名，才能点“确认执行”。
5. 密码只走 SSH 标准输入，不写日志；计划 10 分钟过期；每次执行都会写审计记录。

十二、版本
当前版本：0.2.0
